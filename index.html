Model details, privacy, and interpretation

Two models, unchanged weights.

Xid reads ./person.onnx (a standard COCO YOLOv8n detector, used only for its person class) to find who to box, and ./best.onnx (trained on person_with_id_card) to decide the tag. It never edits or retrains either model. Media stays in this browser.

How the tag is decided.

Every detected person gets a box, numbered left to right. An ID is the union of a face and the lanyard + tag hanging below it, the same two regions the model was trained on: Xid draws a green box around face ∪ tag. Faces turned away or looking down are often missed, so a clear lanyard + tag on a detected person also counts. A face alone never does; that person gets a red “No ID card” box. A hidden or very small card can still read as “No ID card”.

Learn from predictions, not conclusions.

Confidence is a model score, not a calibrated guarantee. Live processing samples frames and may skip frames on slower devices. Never use Xid to grant or deny anyone access.
